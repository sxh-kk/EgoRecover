# G四组最小评估：结论与边界

分析时间：2026-09-30 14:42（UTC+8）。最小评估已于14:05完成；所有12次训练均完成。

协议：222个本轮留出take，开发集选中的best权重，三个训练种子，单个采样draw1062，Euler10，主要Body评分帧t40…199。以下替代此前两个种子开发集末点和单种子留出末点的阶段判断。

## 2. 主要有效因素是预测历史混合训练

- Gaussian源下T2−T0为−17.722mm；三个种子均改善，按take配对95%区间[-21.842,-13.713]mm。
- History源下T3−T1为−18.702mm；三个种子均改善，区间[-22.342,-15.180]mm。
- 这支持在本轮协议中，让G训练时接触预测历史有助于部署时的自身历史闭环；不能推出任意replay实现都有效。
- 旧版整窗口replay曾退化；本轮同时修正地面、参考系、目标配对和观测输入，二者不是同一个训练协议，不能把差异单独归因于某一修复。

## 3. History源的独立收益仍不充分

- GT历史下T1−T0仅−1.350mm，区间[-5.362,+2.745]mm；第三个种子退化。
- 混合历史下T3−T2为−2.330mm，种子差值为−12.111/+4.908/+0.214mm；只有一个种子改善。
- 虽然后一比较的take区间[-4.623,-0.075]mm略低于0，但它先平均了训练种子，不能据此忽略种子方向不一致。区间也未作多重比较校正。
- 三seed平均后，T3在120/222个take上优于T2，PA几乎相同（81.144/81.116mm）。它更多改善head位置（45.034/51.385mm），没有显示稳定的整体姿态优势。
- T3跨三个种子的Body标准差较小，是值得关注的现象；三个种子不足以证明普遍的训练稳定性优势。

## 4. 相对T0改善，相对原E7仍有差距

- T3比T0降低20.051mm，即13.03%；三个种子均改善，176/222个take的三seed平均误差更低。
- T3仍比原E7高18.838mm，即16.38%；仅39/222个take的三seed平均Body优于E7，位置差距不是只由极少数异常take造成。
- 早期“约20%改善”对应两个种子开发集同预算末点；本次“约13%改善”对应三种子留出集best模型。协议不同，后者是当前应优先报告的结果。
- 不能把T0称为原E7。四组共同使用新增历史条件架构，T3−T0不衡量整个改造相对原模型的收益。

## 5. 时间变化误差有明显改善，但不能替代位置精度

T3速度误差281.28mm/s，原E7因果滑窗711.57mm/s，降低约60.5%；说明其相邻帧运动变化更接近GT。T0也为282.09mm/s，四组相近，因此该优势不能主要归因于History源或混合历史，可能与共同的连续历史架构/训练有关，尚未由独立对照分离。

低速度误差不等于已经证明没有过度平滑、没有延迟或动作细节更好；仍需固定片段可视化和动作转折诊断。因此目前可以报告位置精度与时间变化误差的权衡，不能据此宣称全面优于E7。

## 6. 当前瓶颈与下一步

- T3在其自身历史上的P为136.326mm，G为133.856mm，平均纠错2.470mm，约1.81%。它不是独立P-only闭环对照，但提示当前观测对历史误差的纠正仍有限。
- Root99.056mm，root-relative108.720mm，PA81.144mm；位置和姿态都有不足，不能只归因于世界位置，也不能将Body减Root解释为姿态误差。
- 主线可以保留P常速度残差/FK=0及预测历史混合训练。T2应保留为后续强对照，暂不把History源列为已证实的核心优势。
- 后续优先验证观测头参考约束和当前G自身历史适配；当前教师是冻结E7，尚未完成G自身历史刷新。两者均是假设，不是本轮已验证的修复。
- 本次未启动新实验。按用户要求不恢复多draw、低NFE或固定历史额外评价；故障鲁棒性、低步数收益和完整计算成本仍未验证。
