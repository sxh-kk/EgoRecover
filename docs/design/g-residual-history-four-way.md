# G实际历史适配与几何残差：四组实验设计

日期：2026-10-02。状态：已检索原论文并完成设计；训练代码、缓存和正式运行尚未创建。

本轮依据：[R0–R3最终分析](../../exp/egorecover_observation_reference/v2/analysis/final-conclusions.md)。当前最优R0为131.913±2.465mm，原E7共同体型参照115.018mm；G在自身历史上相对P只改善2.386mm。80帧与设备参考未提高全身精度，下一轮固定21帧与预测planar参考。

## 1. 要检验的两个假设

1. 训练混入固定E7历史、推理反馈G自身历史，两种错误不同。让G接触已经实现的R0闭环历史，能否改善实际输入下的单步纠错？这是错误分布适配问题，不要求P预测更长未来。
2. 当前G输出完整身体，P主要作为条件。把G改为在P物理状态上显式输出平移/旋转修正，能否更容易学习观测纠错并减少无必要的重建？完整输出同样有能力纠错；残差结构是否有收益必须实测。

## 3. 四组矩阵

| 组别 | G输出 | 训练历史最终比例 | 唯一因素 |
|---|---|---|---|
| S0 | 原R0完整243D x0 | 50%GT + 50%固定E7 | 同预算续训对照 |
| S1 | P物理状态 + 几何残差 | 50%GT + 50%固定E7 | 残差输出结构 |
| S2 | 原R0完整243D x0 | 50%GT + 25%固定E7 + 25%固定R0闭环 | 实际R0历史来源 |
| S3 | P物理状态 + 几何残差 | 50%GT + 25%固定E7 + 25%固定R0闭环 | 两项组合及交互 |

- S1−S0与S3−S2检验残差结构；S2−S0与S3−S1检验历史来源；(S3−S2)−(S1−S0)报告交互。
- GT与预测混合按整段20帧物理历史选择，不把不同来源的参考增量逐token拼接。全部预测历史占比保持50%。S2/S3的R0比例从0在前1,000更新内升至25%，E7相应从50%降至25%，GT恒为50%。S0/S1始终50%GT/50%E7。
- 每个seed使用上一轮对应R0的dev-selected best作为共同骨干初始化。S0也须新续训，历史R0成绩只作参考，不能代替S0的额外训练预算。

## 4. 实际历史缓存：一次生成、四组共享

- 只使用原清单中的4,369个train episode，不加入dev、222基准take或已用诊断保留集。
- 每个seed冻结对应的R0 best EMA模型，P仍是同一冻结校准P。前20帧使用已核验E7预测启动，t≥20由R0逐帧闭环生成，只读取截至当前帧的21帧原始观测；Euler10，缓存draw1062。
- 每条训练样本取H=[t−20,t)的R0身体状态，与GT(t)配对。不能用包含目标帧的身体状态生成P输入；生成历史时不读GT身体、不用GT重置。
- 缓存存完整物理BodyState。取样时重新编码到本样本上一提交参考，并重新运行冻结P计算μ；不混用E7历史的旧μ/旧参考。
- 固定episode/目标帧/噪声时间与来源选择随机流，S0–S3配对。R0来源槽在S0/S1中读取同一episode/时刻的E7历史，消除采样清单变化。
- 缓存manifest记录R0/P/code哈希、训练清单、启动、观测长度、NFE、draw、完整性和失败。对非有限/无效旋转失败停止生成并记录，不删除失败take，也不自动换GT历史。先用预先固定64个train episode确认稳定与实际生成吞吐，再完成全量缓存；64个pilot不是精度选择集。
- 本轮缓存不刷新：因果解释是“适配固定R0实际历史”，而不是“已解决所有后续模型自身分布”。缓存时间、磁盘量和GPU耗时独立记录。

## 5. 几何残差G的具体定义

P(H)先解码为合法物理状态B_P及其planar参考T_P。G仍读取当前绝对Flow状态x_τ（243D）、20帧身体历史、21帧头/图像及μ。骨干采用R0；残差头输出171D：

- 22个关节各3D旋转修正向量和3D局部平移，共132维。
- P参考的平面dx、dy、yaw修正，共3维。
- 原36维辅助通道的修正。

令L_P,j = inv(T_P) · J_P,j：

T_new = T_P · SE2(δx, δy, δyaw)

R_new,j = Exp(ω_j) · R_P,j

p_new,j = p_P,j + δp_j

J_new,j = T_new · SE3(R_new,j, p_new,j)

aux_new = aux_P + δaux

最后用原codec.encode_current(B_new, H.reference[-1])返回243D完整x0。所有组在同一243D绝对状态空间使用Gaussian源ε、相同插值路径、同一Euler求解和完整表示+dense几何目标；没有同时切换成μ+ε源或在残差空间重新定义Flow。

平移输出尺度为0.1m、旋转为1rad，辅助通道按原motion_std缩放，均不硬裁剪。指数映射必须支持零向量的稳定前向与梯度，并在float32复合/编码。目标旋转为合法SO(3)，不会把6D旋转原始坐标直接相加当作物理旋转。

残差投影头零初始化，初始输出在物理上等于P；绝对组保留R0输出头。输出头维数与初始函数不同是本结构干预的一部分，必须在报告中说明，不能称为仅变量重命名或严格同参数量。骨干规模一致，分别报告参数/FLOPs。P解码后可能规范化参考，所以核验的是零残差物理关节/参考等于P，而非要求原始μ的每个冗余6D通道逐值不变。

表示损失继续作用于重编码后的完整243D x0，geometry=1/FK=0；不新增残差幅度惩罚、观测损失、FK权重或额外多步监督。若模型需要大幅纠错，残差仍允许大修正。该结构可能更依赖不准确P或丢失部分E7输出头能力，收益仍是待验证假设。

## 6. 共同训练预算

| 项目 | 预先固定方案 |
|---|---|
| 数据/P | 复用原1608 train takes/4369 episodes；P冻结，常速度残差，无显式速度 |
| 观测/身体历史 | 21帧观测、20帧身体、10Hz，每次生成当前帧 |
| 参考/地面/体型 | 预测planar参考；已知地面；相同E7预测启动与固定bootstrap beta |
| 初始化 | 每seed对应R0 best骨干；绝对头保留、几何残差头零初始化；重建优化器/EMA |
| 更新数 | 各组12,000步×seeds62/63/64，属于续训，不与原E7全预训练预算等同 |
| Batch | 64，microbatch16×4 |
| 优化器 | AdamW lr3e−5、wd0.01；500步warmup后余弦到0.1倍；EMA0.992028 |
| 梯度 | clip1且非有限时报错；混合精度仅骨干，几何float32 |
| 选点 | 每1,000步，在原固定16个dev take上闭环；按Body均值选EMA best |
| GPU建议映射 | GPU4/5/6/7分别S0/S1/S2/S3；启动时检查实际资源 |
| 正式最终评价 | 222重复使用基准take，三seed，best、Euler10、单draw1062，评分t40…199 |

使用已完成的训练模型，不再次从原E7重训来混淆目标。S0的续训可判断单纯额外预算能否解释改善。三seed不是为挑选最好的seed；全部纳入最终结果。配置设计存于[JSON](../../config/egorecover_g_residual_history_v1.json)，尚无对应运行目录/启动器。

## 7. 少量必要诊断：直接检查每一步纠错

最终222take闭环仍只做原最小评估。在固定16个dev take上另冻结三个身体历史来源：GT、E7、上一轮R0。各来源预先固定32个均匀目标时刻（t20…199），每个模型在完全相同历史、当前观测、噪声、参考和β上做单步预测。

必须同时报告：

1. P的FK误差、G的FK误差、Δ=e_P−e_G，以及G使样本变差的比例和大误差分位数。
2. dense位置与固定β FK位置各自误差；确认几何损失下降是否真正传到最终评分。
3. GT、E7、R0三来源中，残差组是否只适用于一种历史。
4. 少量无头轨迹/无图像对照，检查纠错是否依赖观测。使用现有mask embedding在条件嵌入处屏蔽对应模态，仍保留时间valid mask；不能把头9D置零导致旋转无效。屏蔽全部21帧的该模态，避免从过去观测绕过屏蔽。屏蔽测试是输入敏感性诊断，可能是分布外输入，不能单独证明因果贡献。

这些诊断使用独立固定dev历史，不在各组自身历史上直接比较P→G数值作为唯一结构证据。无需新增旧P、保持或常速度的正式训练组；P仅提供同历史参照。

## 8. 如何判断结果

- S2好于S0：支持适配R0真实反馈错误；若只在固定R0历史好、自己闭环不好，说明固定缓存适配尚未覆盖新模型分布。
- S1好于S0且S3好于S2：支持几何残差输出结构。若只在GT历史好、预测历史退化，则依赖准确P的问题仍在。
- S3最好且固定历史单步纠错也改善：两因素有组合价值。闭环改善但固定历史无改善，也可能主要是历史质量改善，应分开报告。
- dense改善、FK不改善：优先解决输出表示/骨架评分一致性；不根据训练loss声称位置精度有效。
- 四组都相近：此预算与方案未产生可靠收益。不要再次用微小均值差宣称解决约17mm的E7差距。

参考目标：至少比同轮S0降低5mm、三个seed方向一致，并检查take配对区间、速度误差和失效轨迹。5mm是项目实用性目标，不是统计阈值或论文标准。超越原E7仍需同协议位置与延迟证据；本轮不承诺达到100mm。

对四组做配对seed/take统计，置信区间说明训练种子与采样不确定性。222take已用于多轮决策，属于重复基准，不作为全新独立最终泛化证据。严重失效、非有限结果和缓存失败均公开记录；不静默过滤。
