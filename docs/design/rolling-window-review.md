# 滚动窗口重构复核

日期：2026-11-06（Asia/Shanghai）。基线提交：`d6c7de09a3f441e73a49105b52506014588c6041`。依据：[plan.docx](../../plan.docx)，包括 Office Math 公式及两个内嵌 Excel 表格。实现说明：[滚动窗口设计](rolling-window.md)。

## 复核范围

检查了 20 帧世界状态缓存、固定/活动窗口边界、窗口共同参考编码、两类 Flow 源、x0 Euler 求解、冻结 P 的输入梯度、配对分支停止梯度边界、固定体型 FK、相同后续噪声与原始观测、实验预算、数据身份、时间基准、坐标导出和精确恢复。保留原 E7、单帧 G/P 与独立 MotionStreamer 的复现入口，未改变已有实验数值。

## 发现并修复

| 问题 | 修复及证据 |
|---|---|
| 原冻结 P 同时关闭输入梯度，完整后续反馈会被截断 | 仅冻结参数并锁定 eval；测试确认历史输入得到有限非零梯度，P 参数无梯度 |
| 配对后的共同近期状态可能携带当前 G 的梯度 | 复制后停止共同过去的梯度，仅保留当前预测写入；按活动窗口槽位检查仅末槽收到反馈梯度 |
| 分支若复用预测中心/坐标条件，会偏离完整后续映射 | 两份缓存分别调用同一完整 prepare/reconstruct；测试确认参考、中心、头部条件按各自当前写入变化 |
| 反馈对照若使用各自持续更新的后续模型，比较模型会逐渐不同 | 固定初始化 EMA 快照用于后续响应；另维护移动 EMA 选模，测试固定快照全程逐张量不变 |
| 续训反馈组若与未继续训练的基线比较，训练预算不一致 | 显式列出共同 warmup；基线、paired、direct、固定度量各用相同继续训练预算；A/B/C 引用复用 |
| 不同 W 若共用一个采样/噪声随机流，会改变后续训练样本 | 噪声改用独立确定的 episode/step/sample/draw 规则，十个槽位切取窗口；样本与插值时间序列保持一致 |
| 地面归零坐标若直接导出为原始世界坐标，会丢失高度 | 强制读取有限 `floor_height`，同时输出两种坐标及还原变换；测试非零地面和缺失/NaN/布尔高度拒绝 |
| 固定体型损失与数据集 GT 指标口径不同 | 分别报告数据集 `body_mm` 和 `same_shape_mm`，开发集按前者选模；配对响应双方共用同一固定体型 FK |
| 仅恢复模型而未恢复固定后续模型/随机状态，会改变后续训练 | 保存并恢复固定快照、移动 EMA、优化器及全部使用的随机状态；测试分段恢复与连续训练逐张量完全一致 |

## 验证与边界

机器可读记录见 [verification/window_refactor.json](../../verification/window_refactor.json)。验证包含旧代码及新协议测试、完整尺寸 E7 权重迁移及五帧前向、合成训练两步、四种求解步数的两类缓存评估、1/2/4/10 帧配对诊断、两种世界坐标的预测保存，以及代码格式/静态检查。

合成数据和小模型用于集成与梯度验证。当前环境未恢复真实 paired cache、校准 P、原 E7 训练权重和授权 SMPL-X；因此没有新增真实训练、真实 SMPL-X 梯度/资产一致性验证、GPU 性能或精度收益结论。现有合成 SMPL 层回归测试不能代替授权资产验证。默认损失权重、sigma、窗口和 roll-in 长度仍需在开发集固定协议下研究。

在上述验证范围内，复核后未发现阻断提交的问题。
