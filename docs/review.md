# 清理后复核

2026-11-06。依据根目录 [plan.docx](../plan.docx)，清理前版本保存在 [归档分支](https://github.com/sxh-kk/EgoRecover/tree/archive/before-cleanup-20261106)。

本轮检查重点包括：删除后依赖闭包、E7/P 权重身份、冻结模型输入梯度、共同过去停止梯度、窗口世界坐标重编码、一步与多步 Flow、固定体型 FK、单次标签写入的多步诊断、断点恢复、真实/合成模式隔离，以及包安装与资产恢复。

已保留并调整当前协议的测试；删除只针对旧实验接口的测试。新增校验覆盖 E7 EMA 的原学习参数顺序、错误 checkpoint 不部分覆盖模型、删除目录零运行依赖、公共 CLI 全流程、资产分片/归档/原路径映射、哈希校验、拒绝覆盖已有文件及 wheel 内资源。

逐项发现与处理：

- 新窗口网络此前依赖旧单帧 G 的两层继承：已改为一个直接实现的 MotionModel，移除未使用文本参数。
- 数据时间验证此前跨包依赖 MotionStreamer：已移入当前包，保留原有时间契约测试。
- 评估此前导入训练脚本获取通用函数：已将 I/O、checkpoint 和 FK 放到各自模块。
- 核心目录此前保留历史模式/接口：移除旧 SE(3)、保持姿态基线、全网格/其他关节数量分支，当前统一为常速度残差与 SMPL22。
- 多套训练入口/配置/依赖造成主线不明确：统一为四个子命令和可安装包，核心依赖只有 PyTorch。
- 历史大规模发布清单与旧路径混杂：压缩保留所需资产记录，固定远端身份不变，恢复到统一的新目录。

数值复核使用清理前实际完整尺寸模型保存的输入、条件、权重和输出；新模型导入相同 E7 权重后的五帧窗口输出最大绝对差为 0。EMA 训练参数顺序另外与归档实现核对。资产恢复用本地构造的真实字节、分片和 ZIP 测试，不以 mock 成功响应代替哈希验证。

清理完成时的可复验结果记录在 [validation.json](validation.json)。该轮合成流程、模拟 SMPL 层和参数迁移验证不代表真实数据精度、授权 SMPL-X 资产一致性或 GPU 性能。

后续训练前处理已补充：固定 manifest 的划分统计、train/dev 最小资产恢复、授权 SMPL-X 真值解码核验、Conda CUDA 环境、可并行 microbatch 和有效预算记录、多时刻自身连续缓存上的单次注入诊断、配置与依赖命令生成。修复了较晚诊断时刻原先会从 teacher 历史重新启动的问题；当前分支与参考分支都先从实际 G 连续运行状态复制缓存。新增测试覆盖批量损失与独立样本均值一致、非整除 microbatch 的精确断点恢复、划分审计及晚期诊断不重置历史。

在 `egorecover` Conda 环境中重新运行，124 项测试通过；真实 train 样本、校准 P 和授权 SMPL-X 在 A800 上完成两种源分布的成对损失反向传播，G 梯度有限，P、SMPL-X 和冻结 EMA 参数均无梯度。GPU 合成命令行训练及 1/2/4/10 步评估通过。此处真实样本使用未训练小模型做梯度诊断，不是正式训练或精度比较。核验摘要见 [preparation-validation.json](preparation-validation.json)。全量 EE4D train/dev 与 E7 尚未恢复，没有新增外部方法成绩或效率收益结论。

身体指标整合后，解析、因果边界及 CLI 测试共 140 项通过。新增测试覆盖相似变换与反射处理、对齐范围、旋转范数、物理采样间隔、脚滑归一化、聚合口径和指标标签不改变在线输出。独立 review 将脚滑函数与上游固定实现对 40 条不同长度、负高度及空中足点轨迹比较，最大绝对差 `2.665e-15 mm`。真实 dev 样本的 16 个首次输出，在真实 P / SMPL-X / GPU 下验证了全部身体指标有限并与原 `body_mm` 一致；仍为未训练小模型诊断，不代表精度成绩。

复核修复了首帧与稳态 P95 混用、平均各段 FPS/P95 造成的汇总错误。现以实际稳态逐帧耗时计算整体均值、P95 和对应 FPS，报告另列首次被评价查询的耗时。超出帧周期的比例明确为核心计算预算超额，不声称包含排队和整个视觉系统的端到端截止期违约。当前不增加手指重建或手部 MPJPE-H，TMR 与论文 PJ/AUJ 的完整对齐仍明确待完成。
